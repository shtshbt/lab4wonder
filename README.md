# Lab4Wonder

おどろきとはっけんの実験室。家庭で楽しむ182本のインタラクティブHTMLアプリ集です。

## iPadから開く

- [Lab4Wonder入口](https://shtshbt.github.io/lab4wonder/)
- [全アプリ一覧](https://shtshbt.github.io/lab4wonder/explore.html)
- [こども向け一覧](https://shtshbt.github.io/lab4wonder/kids-index.html)

Safariで入口を開き、共有メニューから「ホーム画面に追加」を選ぶと、次回からアイコンで起動できます。

## 収録パッケージ

Claude Mini Apps Explorer r70を収録しています。r70は新規アプリを増やさず、既存アプリの完成度を揃える安定化版です。

## r70

- 全182アプリの共通ナビゲーションに現在の配布版 `r70` を表示。
- `element-sandbox.html` に他アプリと同じ一覧・こども一覧への導線を追加。
- 自由キャンバスのページズーム禁止を解除し、Canvas描画は `touch-action:none` で維持。
- 自由キャンバスに一段階の「元に戻す」を追加。直前の一筆または全消去だけをメモリ内で復元し、保存は行わない。
- 「あそび方」ダイアログへ `aria-expanded`、背景操作抑制、フォーカス循環、復帰フォーカスを追加。
- トップページを版別の長い改修列から「最近のおすすめ4本＋折り畳み履歴」へ整理。
- 182アプリと2一覧を320×800、390×844で横断スモーク監査。

## 維持した内容

- 砂、水、壁、木、火、煙、消しゴムの素材と、落下・流動・沈降・燃焼・消火のコア挙動。
- 現行 `sand.html` の粒状体ラボ。
- 紙飛行機、投擲、砂、配送、飛行船、凧の任意の自己記録と再挑戦。
- 端末保存は明示的にオンにした場合のみ。外部通信なし。

科学模型は概念理解用で、精密な予測や安全判断には使いません。
