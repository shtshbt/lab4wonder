# Lab4Wonder

おどろきとはっけんの実験室。家庭で楽しむ183本のインタラクティブHTMLアプリ集です。

## iPadから開く

- [Lab4Wonder入口](https://shtshbt.github.io/lab4wonder/)
- [全アプリ一覧](https://shtshbt.github.io/lab4wonder/explore.html)
- [こども向け一覧](https://shtshbt.github.io/lab4wonder/kids-index.html)

Safariで入口を開き、共有メニューから「ホーム画面に追加」を選ぶと、次回からアイコンで起動できます。

## オフラインで使う

入口ページ（index / explore / kids-index のどれか）をオンラインで一度開くと、全アプリが自動で端末に保存されます（約14MB）。保存が終わると画面下に「オフラインでも使えます」と数秒表示され、以降は機内モードや圏外でも全アプリを開けます。内容を更新した場合は、次にオンラインで開いたときに自動で新しい版へ入れ替わります。この仕組みは service worker（`sw.js`）によるページの端末内キャッシュで、通信先は引き続き公開サイト自身のみです。

## v1.1.0

- 旧版にあった「手描きフーリエ変換」を、現行の再構成ラボとは別の183本目として復帰。
- ダンゴムシ迷路を、指で壁・出発点・出口を描いて経路を観察できる内容へ刷新。
- アリの巣、粘菌、食物網、鳥の群れ、ホタル、プランクトン、オオカバマダラ、年輪、岩石風化を、場へ直接介入する内容へ刷新。
- ホタルでは木を配置・移動・削除し、遮蔽による同期の変化を実験可能にした。
- 滑車、衝突変形、エンジン、材料疲労、燃焼を、ドラッグ・手回し・スロー観察中心へ刷新。
- スネークとマインスイーパーの自動進行を廃止し、子ども自身が操作するゲームへ変更。
- 川、雨粒、蜃気楼、渦潮、タンカー、飛行船、底なし沼へ、位置に意味のある直接操作を追加。
- 化石形成では最大10個の遺骸を同時に置き、形成・消失理由・実際に残った割合を比較可能にした。
- 深海、洞窟、星座、化石、熱帯雨林、潮だまりの図鑑探索を、場に現れた対象をタップした時だけ同じカードを収集する方式へ変更。
- 生命の系統樹とクモの巣を、枝分岐・補強糸・獲物を主図で直接操作できる内容へ変更。
- 全アプリで「はじめから」の位置を揃え、色・記号の意味を見つけやすくした。
- 紙飛行機の各パラメータと主要な生物・地学用語に、子ども向けの短い説明を追加。
- 子どもに意味のない内部改訂番号、条件署名、内部Canvasバーを画面から除去。

## 維持した内容

- 砂、水、壁、木、火、煙、消しゴムの素材と、落下・流動・沈降・燃焼・消火のコア挙動。
- 現行 `sand.html` の粒状体ラボ。
- 現行 `paper-plane.html` の飛行計算と指で投げる操作（用語説明のみ追加）。
- 端末保存は明示的にオンにした場合のみ。外部通信なし。

科学模型は概念理解用で、精密な予測や安全判断には使いません。
