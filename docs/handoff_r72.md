# 引き継ぎメモ r72

前回セッションはセッションリミットで中断した。完成した改修は `main` に入っており、
公開サイトへ deploy 済み。未完了分は `wip/r72-unfinished` ブランチに退避してある。

## 作業の進め方

改修は 1 アプリ 1 コミットで積む。各アプリの改修後は必ず次を通す。

```bash
bash scripts/validate_release.sh /home/shota/lab4wonder   # 全項目 ok になること
node scripts/check_inline_js.js                            # inline JS の構文チェック
```

ブラウザ検証は playwright + chromium を使う。作業用ディレクトリに導入済みでなければ
`npm i playwright && npx playwright install chromium-headless-shell` を scratchpad で行う。
検証時はローカル配信して開く。

```bash
python3 -m http.server 8123 --directory /home/shota/lab4wonder --bind 127.0.0.1 &
```

`page.on('pageerror')` でエラーゼロを確認し、操作の前後で状態か描画が変わることを
アサートする。アプリは互いに独立なので、複数アプリの改修は並列に進めてよい。

## 全アプリ共通の約束

- 変更対象は原則そのアプリの 1 ファイルだけ。`lab4wonder_v1_1.js` は共有なので、
  触るときは他の改修と同時に走らせない。
- 各アプリは `lab4wonder_v1_1.css` と `lab4wonder_v1_1.js` を必ず 1 回参照する。
  リリース検証が参照数 183 を数えているため、参照を消すと落ちる。
- 画面の文言は日本語で子ども向け。内部の版番号 (r63 等) を新たに書かない。
  文中にダッシュや太字強調を使わない。コードコメントに AI への言及を書かない。
- タップ目標は 44px 以上。pointer イベントでタッチとマウスの両方に対応する。
- モデルの計算は壊さない。見せ方と操作を直すのが基本方針。

## タップ操作の標準パターン

`gas-laws.html` の「えらんでタップ：」ツール列が基準実装。ツールを選ぶと黄色く光り、
図をタップするとその位置に効果と波紋が出て、結果メッセージが帯に表示される。
`minesweeper.html` のモード切替ボタンも同じ考え方。新たにタップ操作を足すアプリは
この見た目と操作に揃える。

## 未完了タスク

### `wip/r72-unfinished` に途中まで入っているもの

いずれも未検証。ブランチの内容を見てから、続けるか捨てて作り直すかを判断する。
各ファイルは読み込み時のコンソールエラーは出ないが、検証は通っていない。

1. **図鑑が 5 種類しか発見できない** (`abyss.html`, `jungle.html`, `lab4wonder_v1_1.js`)
   深海と熱帯雨林で、図鑑に多数の種があるのに 5 種で打ち止めになる。図鑑探索は
   6 アプリ (abyss, cave, constellation-guide, fossil-formation, jungle, tidepool) が
   共有 JS の `installMainExploration` と `watchExplorationAtlas` で動いている。
   tidepool は過去に修正済み (コミット e78354f) なので、その手当てが他に必要か見る。
   あわせて深海はライトの当たった範囲だけ生き物が見えるようにしたい。今はライトの
   意味がない。回帰確認として tidepool の 48 枚到達も必ず見る。

2. **名画ギャラリーの虫眼鏡** (`art-looking-gallery.html`)
   指で押さえた場所を実画像の拡大で見られる虫眼鏡を、全 6 レンズ共通で使えるように
   する。固定位置の拡大まどと倍率切替の下地は `STROKE_VIEWS` と `drawLoupe` として
   main に既にある。canvas は DPR スケーリング済み (論理サイズ 900x620) なので
   座標変換に注意。

3. **形態形成ラボの抽象度** (`field-guided-growth.html`)
   抽象的な濃度場と閾値のままでは伝わらない。モデルは変えず、実際の生物の形に
   対応するプリセット (葉のすじ、動物の模様など、そのモデルが本当に出せる形だけ)、
   やさしい対応の説明、閾値を超えた領域の境界表示を足す。特定の生物専用に
   作り替えるのは改悪なのでやらない。

4. **クモの巣の捕獲演出** (`spider-web.html`)
   獲物がかかった瞬間の衝撃と糸のたわみ、もがき、振動がクモへ伝わる波の可視化、
   捕獲成功と失敗の対比を強化する。

5. **分類樹のカード重なり** (`taxonomy-tree.html`)
   分岐が進むとカードが重なって読めない。葉を等間隔に置き内部ノードを子の中点に
   置く標準レイアウトへ。収まらない場合は自動フィットかパンとズームで到達可能に
   する。検証では全カード矩形の交差が 0 件であることを機械的に確かめる。

6. **年輪ラボのツール選択タップ** (`tree-rings.html`)
   乾燥の年、恵みの雨の年、火事、虫害などを選んでから年輪や年表をタップして
   その年に割り当てる方式にする。
